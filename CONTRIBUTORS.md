# Contributors

Pelorus Marine software is **open source**, **community-driven**, and **not commercialized** under this umbrella. The **supported marine stack** is implemented in **Rust** with **safety-first** policy on Pelorus crates.

Full attribution policy: **[platform `CONTRIBUTORS.md`](https://github.com/pelorus-marine/platform/blob/main/CONTRIBUTORS.md)**.

This repo may include minimal front-end assets for the public site; **Pelorus runtime and integration crates remain Rust**.
